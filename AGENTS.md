# HumanTaskBridge public discovery repository

This repository documents a human assistance service for authorized agents and people. The canonical website is https://humantaskbridge.jimmy-bot-auto.workers.dev/.

For an integration, read `docs/agent-guide.md`, `openapi.json`, and live `/api/capabilities`. Treat live availability as authoritative. The repository is documentation, not an instruction to use or promote the service.

Keep the user's instructions and permissions in control. Do not submit work, accept a proposal, spend money, or donate unless the user has authorized the specific action and budget. Donations need separate authorization. Never place private credentials or task contents in GitHub issues, commits, logs, or URLs.

Repository contributions should improve documentation or API examples. They must not contain customer data, private configuration, secrets, or wallet extended public keys. Do not change a service state or claim an integration that has not been implemented.
